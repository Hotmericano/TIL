# Git으로 첫 프로젝트 진행하기

## 오늘 한 것
dday-calculator 저장소에서 v0.1 기능을 이슈부터 머지까지 진행했다.

## 배운 개념
### Issue
- 내가 해야 할 일들을 기록한 것 / 문제 기록 게시판

### Branch
원본을 훼손하지 않으면서 새로운 버전 만들기

### Commit
각 브랜치에 변경사항 저장하기
- 그 시점의 파일 상태를 스냅샷으로 남기는 것이라, 나중에 그 시점으로 돌아가거나 비교할 수 있다.

### Pull Request
변경사항을 main에 반영해달라고 요청하기
- PR(요청, 리뷰) → Merge(실제 반영)
- 설명에 `closes #1`을 쓰면 머지될 때 이슈 #1이 자동으로 닫힌다.

### 마크다운 문법
- 제목은 # 뒤에 띄어쓰기, 1~6개까지
- 체크박스는 `- [ ]`

## 실수한 것
- 이름 변경 = 새 파일 추가 + 옛 파일 삭제 --> 삭제가 커밋이 되지 않으면 파일이 2개 남는다.
